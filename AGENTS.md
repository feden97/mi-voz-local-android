# Entrega de APK

- El usuario pidió que cada APK entregada se publique en una release de GitHub y
  que se devuelva su enlace de descarga; un enlace local no completa la entrega.
- Repositorio: `feden97/mi-voz-local-android`. Conservar applicationId y certificado
  para permitir instalar encima sin borrar voces, modelos e historial.
- No subir registros personales, adjuntos, audios, pesos, credenciales ni claves.
- GPU está deshabilitada desde 0.3.3 tras un bloqueo completo del S23 Ultra. No
  reactivar esa ruta como parte de una optimización rutinaria de CPU.
